# 高松総合法律事務所 ウェブサイト

> **Service.01　Web・アプリ開発**ーー試作：TanStack Start / React / Tailwind CSS　納品：WordPress

香川県高松市の法律事務所サイトのリニューアル案です。**コラムを軸にした情報発信と、事務所のブランディング**を目的として構成しています。（集客・問い合わせ獲得を主目的とした設計ではありません。）

本リポジトリはデザインと導線を確認するための**試作環境**です。納品は WordPress で行います。試作で確定した構成・仕様は [`docs/`](./docs) にまとめてあり、そのまま WordPress 側へ移せる形にしています。

## 設計の要点

- **コラムは独立した投稿タイプ。** 固定ページ・お知らせと混ざらず、分野ごとのアーカイブ（`/column/category/<分野>`）を持ちます。記事が増えても管理画面が散らかりません。
- **全文の正本は当サイト。** 各記事に絶対URLの `canonical` を出力しています。将来 note に要約を載せても、検索エンジンからの評価は当サイトに集約されます。
  → [docs/note-operation.md](./docs/note-operation.md)
- **読ませるための本文設計。** 記事冒頭の要点、目次（見出しから自動生成・スクロール追従）、読了目安時間、前後の記事への送り、共有ボタン、執筆者情報。本文は 16.5〜17px / 行間 2.05 で、60代・70代の閲覧を前提にしています。
- **反応が見える。** 記事の表示だけでなく、本文を 50% / 90% まで読み進めた割合を計測します。「開かれた数」と「最後まで読まれた数」を分けて取ることが、note で何を出すかの判断材料になります。
  → [docs/seo-migration.md](./docs/seo-migration.md)
- **旧サイトの評価を引き継ぐ。** 旧URLから新URLへの 301 を、記事データから自動生成しています。日本語URLにも対応。
- **弁護士の写真は使わない。** 氏名の一文字からロゴのダイヤをモチーフにしたシンボルマークを生成し、無機質にならないようにしています。
